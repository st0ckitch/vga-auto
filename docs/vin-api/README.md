# VIN სერვისი საიტისთვის (vin-api.php)

ერთი PHP ფაილი (PHP 5.6 ან უფრო ახალი, დამატებითი ბიბლიოთეკების გარეშე), რომელიც VIN კოდით აბრუნებს
JSON-ს: ავტომობილის მონაცემები და ფოტოები 4 ეტაპის მიხედვით. მას იძახებს მხოლოდ საიტის სერვერული
ნაწილი (Cloudflare), ბრაუზერი პირდაპირ არა. საიტი პასუხს თავად ხატავს გვერდზე vgae.com.ge/search/.

## დაყენება (დილერის სისტემის მხარე)

1. ატვირთეთ `vin-api.php` სერვერზე, მაგალითად: `https://account.vgae.com.ge/dlr/vin-api.php`
2. ფაილის თავში, `$CFG` ბლოკში, შეავსეთ:
   - `api_key` - გრძელი შემთხვევითი სტრიქონი (მაგ. 40 სიმბოლო). იგივე მნიშვნელობა უნდა მოგვცეთ ჩვენ,
     რომ საიტმა გამოიყენოს. უსაფრთხოდ გადმოგზავნეთ (არა საჯარო ჩატში).
   - `db_dsn`, `db_user`, `db_pass` - ბაზასთან კავშირი (PDO).
   - `sql_car` - მანქანის ამორჩევა VIN-ით. სავალდებულოა მხოლოდ `id` და `vin`. ალიასები make, model,
     year, lot, auction, status, stage (1-4), location, container, eta, updated_at საიტმა იცის და სამ
     ენაზე თარგმნის - რაც არ გაქვთ, უბრალოდ წაშალეთ. WHERE-ში უკვე წერია `AND c.active = 1`, რომ
     მხოლოდ აქტიური მანქანები მოიძებნოს (არააქტიურზე პასუხი 404 იქნება).
   - **სხვა ველები** - თუ თქვენი სისტემა სხვა ინფორმაციას ინახავს, დაამატეთ ნებისმიერი სვეტი და
     ალიასად ჩაწერეთ სათაური, რომელიც საიტზე გამოჩნდება:
     - `c.color AS 'ფერი'` - სტრიქონი "ფერი: ..." მანქანის მონაცემებში;
     - `c.vessel AS '3:გემი'` - სტრიქონი მე-3 ეტაპის შიგნით (პრეფიქსი `1:` `2:` `3:` `4:` = ეტაპი);
     - `c.color AS 'ფერი|Color|Цвет'` - სათაური ენების მიხედვით (ქართული|ინგლისური|რუსული), არჩევითი.
     ცარიელი მნიშვნელობები არ ჩანს. ყველაფერი, რაც აქ ამოირჩევა, საიტზე **საჯაროდ** გამოჩნდება -
     მფლობელის სახელი, ტელეფონი, ფასი და სხვა პირადი მონაცემი არ ამოირჩიოთ.
   - `stages` - ფოტოები: თითო ეტაპზე (1 აუქციონი, 2 ტრანსპორტირება აშშ-ში, 3 პორტი აშშ-ში, 4 ფოთი)
     ცალკე SQL და ცალკე საქაღალდე, ანუ თითოეულ ეტაპს შეიძლება ჰქონდეს თავისი ცხრილი და თავისი ფოლდერი:
     - `sql` - უნდა დააბრუნოს სვეტი `path` (ფაილის სახელი/ბილიკი ან სრული URL); არჩევით `thumb`
       (დაპატარავებული ასლი) და `created_at` (ფოტოს თარიღი). WHERE-ში გამოიყენეთ `:car_id`
       (sql_car-ის id) ან `:vin` - რომელიც თქვენს ცხრილშია.
     - `base` - ამ ეტაპის ფოტოების საქაღალდის საჯარო მისამართი, ემატება შედარებით ბილიკებს.
     - `thumb_base` - იგივე დაპატარავებული ასლებისთვის (არჩევითი; თუ არ არის, `base` გამოიყენება).
       თუ ასლების სვეტი საერთოდ არ გაქვთ, წაშალეთ `p.thumb AS thumb,` - მაშინ ბადეშიც სრული ფოტო
       ჩაიტვირთება.
     - ყველა ეტაპი ერთ ცხრილშია? იგივე SQL დაწერეთ ოთხჯერ, სხვადასხვა WHERE-ით (მაგ. `AND p.stage = 2`).
3. თუ სისტემაში უკვე არის კოდი, რომელიც VIN-ით მანქანასა და ფოტოებს პოულობს, SQL-ების ნაცვლად
   შეცვალეთ `load_car()` ფუნქციის შიგთავსი. ის უნდა დააბრუნოს `build_result(...)` ან `null`, თუ VIN
   უცნობია (`build_result`-ის პარამეტრები ფაილშია აღწერილი).

მნიშვნელოვანი: ფოტოების მისამართები საჯაროდ უნდა იხსნებოდეს (ავტორიზაციის გარეშე) და https-ით,
რადგან მომხმარებლის ბრაუზერი მათ პირდაპირ ტვირთავს.

## შემოწმება

```
# გასაღების გარეშე - 401
curl -i "https://account.vgae.com.ge/dlr/vin-api.php?vin=JM3KFBCM8M1372923"

# გასაღებით - JSON
curl -i -H "X-Api-Key: თქვენი-გასაღები" "https://account.vgae.com.ge/dlr/vin-api.php?vin=JM3KFBCM8M1372923"
```

## მოთხოვნა

- მეთოდი: `GET`
- პარამეტრი: `vin` - 5-17 სიმბოლო, ლათინური ასოები და ციფრები (სერვისი თავად აქცევს დიდ ასოებად)
- ჰედერი: `X-Api-Key: <api_key>`

## პასუხი (200)

```json
{
  "ok": true,
  "vin": "JM3KFBCM8M1372923",
  "car": {
    "make": "Mazda",
    "model": "CX-5",
    "year": 2021,
    "lot": "58123456",
    "auction": "Copart",
    "status": "კონტეინერში ჩატვირთულია",
    "stage": 3,
    "location": "Savannah, GA",
    "container": "MSCU1234567",
    "eta": "2026-11-20",
    "updated_at": "2026-10-18 14:02:00"
  },
  "info": [
    { "label": "ფერი|Color|Цвет", "value": "თეთრი" },
    { "label": "გასაღები", "value": "არის" }
  ],
  "stages": [
    { "id": 1, "name": "აუქციონი", "date": "2026-09-30", "info": [], "photos": [
        { "url": "https://account.vgae.com.ge/uploads/auction/a1.jpg", "thumb": "https://account.vgae.com.ge/uploads/auction/thumbs/a1.jpg" },
        { "url": "https://account.vgae.com.ge/uploads/auction/a2.jpg", "thumb": "https://account.vgae.com.ge/uploads/auction/thumbs/a2.jpg" }
    ] },
    { "id": 2, "name": "ტრანსპორტირება აშშ-ში", "date": "2026-10-05", "info": [], "photos": [] },
    { "id": 3, "name": "პორტი აშშ-ში", "date": null, "info": [ { "label": "გემი|Vessel|Судно", "value": "MSC AURORA" } ], "photos": [] },
    { "id": 4, "name": "ფოთი", "date": null, "info": [], "photos": [] }
  ]
}
```

- `car` - ყველა ველი არჩევითია; რაც ბაზაში ცარიელია, პასუხში არ ჩანს. `year` და `stage` რიცხვებია.
- `car.stage` - მიმდინარე ეტაპი (1-4). თუ არ არის, სერვისი აიღებს ბოლო ეტაპს, რომელსაც ფოტო აქვს.
- `info` - დამატებითი ველები თანმიმდევრობით: `label` სათაურია (ერთი სტრიქონი ან `ka|en|ru`),
  `value` მნიშვნელობა. საიტი მათ ცნობილი ველების შემდეგ აჩვენებს. ასეთივე `info` სია აქვს თითოეულ
  ეტაპსაც (`stages[].info`) - ის ეტაპის სათაურის ქვეშ ჩანს.
- `stages` - ყოველთვის 4 ეტაპი, თანმიმდევრობით. `name` სათადარიგოა - საიტი ეტაპებს თავისი სამი ენის
  სახელებით აჩვენებს. `date` - ეტაპის პირველი ფოტოს თარიღი (YYYY-MM-DD) ან `null`.
- `photos` - თითო ეტაპზე მაქსიმუმ 80. თითოეული ფოტო არის ობიექტი `{ "url": ..., "thumb": ... }`:
  `url` სრული ფოტოა (იხსნება გადიდებისას), `thumb` დაპატარავებული ასლი (ჩანს ბადეში, სასურველია
  400-600 px სიგანის). თუ ასლი არ არის, `thumb`-ში იგივე `url` წერია. უბრალო სტრიქონიც მიიღება
  (`"https://.../1.jpg"`) - მაშინ ბადეშიც სრული ფოტო ჩაიტვირთება.

## შეცდომები

| კოდი | პასუხი | როდის |
| --- | --- | --- |
| 400 | `{"ok":false,"error":"bad_vin"}` | VIN არასწორი ფორმატისაა |
| 401 | `{"ok":false,"error":"unauthorized"}` | გასაღები არასწორია ან `api_key` არ შეცვლილა |
| 404 | `{"ok":false,"error":"not_found","vin":"..."}` | ასეთი VIN ბაზაში არ არის |
| 405 | `{"ok":false,"error":"method_not_allowed"}` | არა GET მოთხოვნა |
| 500 | `{"ok":false,"error":"server_error"}` | ბაზის/SQL შეცდომა (დეტალები JSON-ში არ გადის) |

## უსაფრთხოება

- გასაღები მოწმდება მუდმივი დროის შედარებით (`hash_equals`), სერვისი მუშაობს მხოლოდ GET-ით.
- VIN მოწმდება რეგულარული გამოსახულებით და SQL-ში მხოლოდ პარამეტრად გადადის (PDO).
- PHP-ის გაფრთხილებები პასუხში არ ჩანს (`display_errors=0`), პასუხი არ ქეშირდება (`no-store`).
- სერვისი მონაცემებს არ ცვლის, მხოლოდ კითხულობს.

## საიტის მხარე (ჩვენი ნაწილი)

Cloudflare -> Workers & Pages -> vga-auto -> Settings -> Variables and Secrets:

- `VIN_API_URL` = `https://account.vgae.com.ge/dlr/vin-api.php` (Text)
- `VIN_API_KEY` = ის გასაღები, რაც `vin-api.php`-ში ჩაიწერა (Secret)

ამის შემდეგ საიტის `/api/vin?vin=...` სერვისს სერვერიდან ეკითხება, პასუხს 2 წუთით ქეშირებს და
გვერდი მანქანას, მონაცემებს და 4 ეტაპის ფოტო-გალერეას თავად აჩვენებს. სანამ ეს არ არის
დაყენებული, გვერდი ძველებურად აჩვენებს დილერის სისტემის საძიებო გვერდს ფრეიმში.
